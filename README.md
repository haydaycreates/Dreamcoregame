# Liminal Drive — v2

Single-file dreamcore driving game (`index.html`). Open it directly in a browser, or `npm i && npm run dev`.
`index.original.html` is the previous version, kept for reference.

## What changed in v2
- Auto-cruise + rotating camera: you only steer. Drag anywhere (mobile) / A-D (desktop). Boost & brake buttons.
- Hazards: thorns, static blocks, slow puddles, and Watchers that chase you from Depth 2.
- Depth levels every ~1.5 km — more hazards, faster energy drain, banner + bonus energy.
- Combo multiplier (x1–x5), near-miss bonuses, boost meter (invulnerable, x2 score, shatters hazards).
- Power-ups: Shield, Magnet, Lucid x2, Burst. Portals teleport you to a new dream.
- One revive per run. Daily missions, achievements, lifetime stats, dream-shard currency, Garage (8 skins, 5 trails).
- Synthesized WebAudio ambience/SFX (M or ♪ to mute), haptics, auto-pause on tab switch. All progress in localStorage.
